# Bramble Buddies Releases

Public Windows installers and automatic-update packages for the private Bramble Buddies beta.

Download the latest `BrambleBuddies.App-win-x64-Setup.exe` from [Releases](https://github.com/i-snyder/bramblebuddies-releases/releases/latest). Builds are currently unsigned, so Windows may require **More info → Run anyway**.

This repository intentionally contains no application source code. Release assets and filenames are managed by the private source repository's Velopack publishing workflow.
